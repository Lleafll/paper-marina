
This folder contains all the Two Step logfiles from training (only in B4-session 1) and fMRI session.
There should be 1 logfile with the word "training  and 3 logfiles with the session number as prefix (i.e. 1, 2, 3).
The folder "Files without Timestamp" contains the logfiles with the short SubjID.Please keep in mind, that this folder is not complete. All participants that needed repair are missing because only the files with timestamp are repaired.

The folder called "Files_with_wrong_SubjID" contains VALID subject logfiles with wrong ID (due to typos, incomplete or eexchanged numbers, etc) and should be changed and this change should be documented during the QC process.

The folder called "incomplete, aborted, crashed..." contains test, aborted or crashed data that should stay there in case we want to explain some missing information

The folder called "Test Runs" contains all test runs as for example "9999", "8888" or "0000".

The folder called "Training" contains all training logfiles.

The folder called "all_data_sync" contains all data.
